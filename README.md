# Phishing Email Detection Model

A simple Machine Learning project using **Python** and **Scikit-learn** to classify emails as **Phishing** or **Safe**.

## Features

* Email text preprocessing
* TF-IDF feature extraction
* Naive Bayes classification
* Accuracy and confusion matrix display
* Custom email prediction

## Technologies Used

* Python 3.13
* Pandas
* Scikit-learn
* Matplotlib
* Seaborn

## Run the Project

Install dependencies:

```bash id="3v4c2n"
pip install pandas scikit-learn matplotlib seaborn
```

Run the program:

```bash id="tw5wkh"

```

* Detects phishing emails
* Shows prediction accuracy
